Resume-to-Job Description Gap Analyzer
Semester Project Plan — Mid-Sem and End-Sem Breakdown
This plan divides the project into two halves. The mid-semester milestone delivers a working, deployed tool
using keyword-based matching. The end-semester milestone upgrades the core algorithm to semantic
(embeddings-based) matching and adds personalization and testing depth — showing clear technical growth
over the semester.

Why This Split Scores Well
Mid-sem shows working software with a legitimate (if simple) NLP technique. End-sem shows a genuine
upgrade to the core algorithm (keyword matching fi embeddings) rather than just added UI polish, plus a
standout closing-the-loop feature: the tool doesn't just tell the user what's wrong, it generates an updated
resume for them. That before/after comparison and the auto-generated output demonstrate real technical
growth and end-to-end usefulness — exactly what strong software engineering rubrics reward.
