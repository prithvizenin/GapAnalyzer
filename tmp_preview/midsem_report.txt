          Resume-to-Job Description Gap Analyzer

                               Mid-Semester Progress Report

1. Project Overview

The Resume-to-Job Description Gap Analyzer is a tool that compares a user's resume against a target job
posting and surfaces the gap between the two -- which skills and keywords the posting emphasizes that the
resume does not clearly reflect. The semester plan splits development into two halves: a mid-semester
milestone built around keyword-based matching, and an end-semester milestone that upgrades the core
algorithm to semantic (embeddings-based) matching with added personalization and testing depth.
This report covers the mid-semester milestone (Weeks 1­7), which is now complete.

2. Mid-Semester Objective

Deliver a working, deployed, end-to-end tool that can:
  · Accept an uploaded resume (PDF/DOCX) and a pasted job posting
  · Extract clean text and identify relevant skills/keywords from both
  · Score the match using a keyword-overlap / TF-IDF approach
  · Present a match percentage and a list of missing keywords through a simple UI

5. Current Limitations

As expected at this stage, the tool relies on exact or near-exact keyword matching. This means it does not
yet:

  · Recognize paraphrased or synonymous skills (e.g., "led a team" vs. "management experience")
  · Categorize skills into technical / soft / tools groupings
  · Offer specific, actionable suggestions beyond a list of missing keywords
  · Generate a revised resume automatically
These gaps are the intended target of the end-semester phase.

6. Next Steps -- End-Semester Plan (Weeks 8­14)

  · Weeks 8­9: Upgrade matching to sentence embeddings so paraphrased skills are caught, not just exact
       keyword hits

  · Weeks 10­11: Cluster extracted skills into categories and generate specific, targeted suggestions
  · Week 12: Build an automated resume-update feature that incorporates missing skills into natural

       resume language, with side-by-side review and PDF/DOCX export
  · Week 13: Test with 5+ real resumes/postings from classmates and refine based on feedback
  · Week 14: Final report with a keyword-only vs. embeddings comparison, plus a live demo

7. Summary

The mid-semester milestone is complete: the tool is deployed, end-to-end functional, and performing
keyword-based gap detection as planned. The remaining semester will focus on upgrading the matching
engine to embeddings-based semantic matching and adding the personalization and auto-generation
features that build on this foundation.
